# v0.2.0

**Release Date:** 2026-05-17

Repository renamed from `plexusone/capability-stack-spec` to `grokify/prism-capability` as part of the PRISM ecosystem consolidation.

## Highlights

- **Repository Rename**: Moved from `github.com/plexusone/capability-stack-spec` to `github.com/grokify/prism-capability`
- **PRISM Ecosystem**: Now part of the unified [PRISM ecosystem](https://github.com/grokify/prism)

## Breaking Changes

### Import Path Change

Update your Go imports:

```go
// Before
import capstack "github.com/plexusone/capability-stack-spec"
import "github.com/plexusone/capability-stack-spec/render"
import "github.com/plexusone/capability-stack-spec/schema"

// After
import capstack "github.com/grokify/prism-capability"
import "github.com/grokify/prism-capability/render"
import "github.com/grokify/prism-capability/schema"
```

### Installation

```bash
# CLI
go install github.com/grokify/prism-capability/cmd/capstack@latest

# Library
go get github.com/grokify/prism-capability
```

## Changes

| Component | Change |
|-----------|--------|
| Go module | `github.com/plexusone/capability-stack-spec` -> `github.com/grokify/prism-capability` |
| JSON Schema $id | Updated to `https://github.com/grokify/prism-capability/schema/capability-stack.schema.json` |
| README | Updated badges, installation instructions, and import examples |

## Migration Guide

1. Update `go.mod` to use the new module path
2. Run `go mod tidy` to update dependencies
3. Update all import statements in your code
4. The API remains unchanged - only the import paths have changed
