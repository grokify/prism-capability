# v0.3.0

**Release Date:** 2026-05-18

## Highlights

- **Market Integration**: New `MarketRef` type for linking organizational capabilities to market capabilities from [market-strategy-engine](https://github.com/grokify/market-strategy-engine)
- **PRISM Core Integration**: Types now imported from [prism-core](https://github.com/grokify/prism-core) v0.1.0

## Added

### MarketRef Type

Capabilities can now reference market capabilities for strategic alignment:

```json
{
  "id": "sast",
  "name": "SAST",
  "marketRef": {
    "marketId": "enterprise-security",
    "capabilityIds": ["secure-sdlc", "compliance-automation"],
    "segments": ["enterprise", "regulated"],
    "impact": "high",
    "gapContribution": [
      {
        "capabilityId": "secure-sdlc",
        "segmentId": "regulated",
        "contribution": "primary",
        "description": "Enables shift-left security for regulated industries"
      }
    ]
  }
}
```

### MarketIntegration Configuration

Global market integration settings at the document level:

```json
{
  "marketIntegration": {
    "analysisRef": "market-analysis-2026-q2.json",
    "defaultMarket": "enterprise-security",
    "focusSegments": ["enterprise", "mid-market"]
  }
}
```

### New Query Methods

- `CapabilitiesByMarketCapability(marketCapID)` - Find org capabilities that enable a market capability
- `CapabilitiesByMarket(marketID)` - Find org capabilities linked to a specific market
- `CapabilitiesForSegment(segmentID)` - Find org capabilities that benefit a market segment

## Changed

### prism-core Integration

The following types are now imported from `github.com/grokify/prism-core` instead of being defined locally:

| Type | Package |
|------|---------|
| `Priority` | `prism-core` |
| `Domain` | `prism-core` |
| NIST CSF functions | `prism-core` |

This ensures consistency across the PRISM ecosystem.

### JSON Schema

The JSON Schema has been regenerated to include:

- `MarketRef` type definition
- `GapContribution` type definition
- `MarketIntegration` type definition
- `marketRef` field on Capability
- `marketIntegration` field on CapabilityStack
